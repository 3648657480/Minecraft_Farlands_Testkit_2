# Alpha1 范围（冻结，2026-11-15）

> 负责人决定：Alpha1 只需保证 **2^53（门禁）/ 2^63（上限）以内可用**；
> 2^63 以外（2^88 / 171.103 的"经典高墙"等）归 **Alpha2**，本轮不做。
> 本页是 Alpha1 的"完成定义"；与本页冲突的旧文档（ROADMAP 的 W1–W5 进度、STATUS.md）以本页为准。

## 1. 坐标边界

| 区间 | 承诺 | 依据 |
|---|---|---|
| \|x\|,\|z\| ≤ 2^53 | **门禁承诺**：必须通过五门 + 实机可用 | `verify.ps1` 5/5；2^53 多轮实机 |
| 2^53 < \|x\|,\|z\| ≤ 2^63−1 | **尽力可用**（同一管线，不额外承诺） | 2026-11-15 实测 x=2^63：`store=81 uncompiled=0 farMeshSec=323`，本地帧 base=2^59/local=−1 正常，无 crash |
| > 2^63−1 | **不在 Alpha1** | 2026-11-15 实测 x=2^64：double→long 饱和、AABB=±9.23e18、身份不可信 |

注意：`pSec`/`viewC` 等诊断里出现的 `-1` 是 int 视图（有损桥），不是身份；
判断"是否到界"看 `farKeyChunks`、`[WIDEBASE] base/local`、`meshGlobal`，不要看 int 视图。

## 2. Alpha1 要做到（验收）

1. `tools/verify.ps1 -Mode all` **5/5**（norm / seam / coll / save / dist53）；
2. 安装形态（PCL2 版本目录）能启动、能进世界，**无崩溃、无日志洪水**
   （一次 2 分钟会话日志 ≤ 数千行；`[WGWARN]` 只出现一次）；
3. 2^53 实机：能传送、能看、能走、能存；`uncompiled=0` 能收敛；
4. 现象要求：能复现 G1 `EXPERIMENTS.md` §8 的**机制阈值**（不是"好玩"的画面）：
   - 2^53：密度按 2 格成对（round-to-even 分组）；
   - 2^55：密度按 8 格平台；
   - 记录在 `docs/PHENOMENA.md`（P7/P8）。
5. 已知问题清单在 §4；这些**不阻塞** Alpha1 发布。

## 3. Alpha1 明确不承诺

- 多人 / dedicated server（`G2Mod` 已在 dedicated 关闭 Y 窗口并打印告警）；
- 真实光照（远域全亮护栏；2^53 的阴影现象不承诺）；
- 结构/特征在 2^31 缝上的"内容正确性"（已知 int 回绕，`[WGWARN]` 计数为证）；
- 2^55+ 的**目视形态**（阶梯/平板/水面瓷砖）——只承诺密度层阈值可复现；
- 2^63 以外的任何坐标（2^88/171.103 高墙、2^1016 等，Alpha2）；
- 性能目标（首屏收敛时间只记录、不作为门禁）。

## 5. Alpha2 预览（不在本轮）
