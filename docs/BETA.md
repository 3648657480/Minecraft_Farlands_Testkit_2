# Alpha1 内测包（距离现象版）

> 目的：只交付**已知**的距离现象，让内测者告诉我们"缺了哪些、和预期差在哪"。
> 规则：内测报告只作观察记录；不与 Wiki/社区记录做"谁更准确"的比较（R10）。
> 负责人 2026-11-15 决定：Alpha1 只保证 2^63 或 2^53 以内可用，2^63 以外归 Alpha2。

## 1. 内测者拿到什么

| 文件 | 位置 |
|---|---|
| fork jar | `versions/26.2-Fabric_0.19.3_fork_v2/26.2-Fabric_0.19.3_fork_v2.jar` |
| mod | 同目录 `mods/farlands-g2-mod-0.1.0.jar` |
| 版本 | `0.1.0`（启动日志 `[FarLands-G2] 0.1.0 wide build (real coordinates)`） |

安装方式就是 PCL2 的这个版本目录，**不要**替换 mod 或 jar（两者强绑定）。
启动后确认日志里有上面那行版本行，再看 `[FarLands-G2] env/ jvm/ farlands.* properties` 打印是否正常。

## 2. 怎么去（单人 + 作弊开启）

- 本版本**不支持联机**；多人/dedicated 会打印不支持告警。
- 世界必须开作弊，用 `/tp @s <x> <y> <z>`（y 建议 120~200、俯视 45°）。
- 目标坐标（Alpha1 覆盖内）：

| 量级 | x | 说明 |
|---|---|---|
| 2^53 | 9007199254740992 | 已知：2 格一组、**地表正常** |
| 2^55 | 36028797018963968 | 已知：规则阶梯/条带（"奶酪状"） |
| 2^56 | 72057594037927936 | 已知：平板状结构 + 水面瓷砖（16 格） |
| 2^62 | 4611686018427387904 | 2^63 区域的代表点（**不要**用 2^63 本身，会饱和到 long 上限） |

> 传送后如果画面一开始是空的：等 15–30 秒让它编译；仍为空再报。

## 3. 已知现象清单（G1 `EXPERIMENTS.md` §8，本项目条件下）

| 坐标 | 已知现象 | 内测要看什么 |
|---|---|---|
| 2^53 | 1 格采样量化为 **2 格成对**；**地表正常**、地下细微 | 地表是否"看起来正常"（正常 = 与预期一致，不是 bug）；地下/剖面是否有 2 格重复 |
| 2^55 | **主地形量化：规则阶梯/条带（奶酪状）** | 是否能看出规则的台阶/条带；周期大约多少格 |
| 2^56 | **平板状结构 + 水面瓷砖（16 格）** | 是否出现大块平板；水面是否呈 16 格瓷砖 |
| 2^63 区域 | 同质拼图（128 chunk 均匀块）——**Alpha2 外推，本版本只做记录** | 仅记录，不作为验收 |

**注意**：2^53 的"地表正常"是**已知结论**，不是缺失；不要把它报成 bug。

## 4. 只报这些（其他先不报，避免噪声）

- ✅ 距离现象：预期有的没有、周期不对、位置不对、只在某个方向出现。
- ✅ 崩溃 / 无法启动 / 日志洪水（一次 2 分钟会话日志超过几百 KB）。
- ✅ 2^53 以内传送失败、方块交互完全失效、画面永久空洞（等 60 秒仍不收敛）。
- ❌ 2^31 缝上的结构/村庄/竹子异常（已知 int 回绕，Alpha1 不修）。
- ❌ 光影/光影包、性能帧数、HUD 美观、F3+G。
- ❌ 2^63 以外（2^88/171.103 等）——Alpha2。

## 5. 报告模板（每条现象一份）

```text
版本:      0.1.0   (启动日志版本行)
jar/mod:   fork_v2 + farlands-g2-mod-0.1.0.jar   (sha256 若方便)
世界:      种子=____（创建世界界面可复制）/ 是否新世界
坐标:      x=____ y=____ z=____   yaw=____ pitch=____
量级:      2^53 / 2^55 / 2^56 / 2^62
预期:      你预期看到什么（一句话）
实际:      你看到什么（一句话；截图为准）
复现:      重进世界/重传同坐标 是否一样
附件:      截图（F3 打开）+ latest.log
```

## 6. 已知问题（不用报，已在 `docs/ALPHA1.md` §4 记账）

- 2^31 缝上 feature 读镜像 chunk（`[WGWARN]` 已限流）；
- 地形条纹（1 格沟槽/台阶）尚未定性；
- 客户端 `getBlockState` 在远域返回空气（因此画面之外的数据要我们服务端探针取）；
- HUD 未并入 F3、F3+G 远域不可用；
- 远域光照为全亮护栏（阴影类现象本版本不承诺）。

## 7. 内测结论怎么用

- 每条报告按"量级 → 现象 → 是否可复现"归档；
- 同一量级有 ≥2 人独立报"缺失"→ 进 Alpha2 的待查清单；
- 只有 1 人报且无法复现 → 记录，不追；
- 与 G1 §8 记录冲突时，按 R10 只陈述差异与条件，不判定谁对。
