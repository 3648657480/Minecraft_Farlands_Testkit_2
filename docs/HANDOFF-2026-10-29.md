## 6. 类型契约（不要破坏）

- 身份：`WideChunkPos` 2048-bit / `WideSectionKey2560` 2560-bit；`Vec3i` 每轴 inline 128（`xLo/xHi`）。
- `getX()I` / `getLongX()J` 是**视图**，不是身份；远 Y/远 X 必须用 `getLongX/getLongY/getLongZ` 或 `getWide*`。
- int 视图永远不能重建身份；double 只承载现象（渲染/噪声/声音衰减），不做键。
- frame（`FramedPos`、碰撞帧）不序列化、不跨系统传播；epoch 已墓碑化（T1），不要复活。
- 详见 `C:\Project-G2-aux\docs\TYPE-CONTRACT.md`。

## 7. 工程纪律与坑

- 改 patcher 必须 bump `PATCH_REVISION`，否则 loom 会静默复用旧 jar。
- 运行用的 jar 来源要看 `mod\build\loom-cache\argFiles\runServer`，不是随便挑 `minecraft-merged-*.jar`。
- **必须确认客户端进程是修复后启动的**：多次出现"世界在旧 JVM 里加载"，看起来像修复无效。重启前先 `Get-CimInstance Win32_Process -Filter "Name='java.exe'"` 看启动时间。
- Mixin 偶尔"注册了但没生效"（Heightmap 那次），关键守卫优先用 patcher（字节码直改）而不是 mixin。
- 卡死优先抓线程栈：`jcmd <pid> Thread.print`，看 `"Server thread"` 的 RUNNABLE 栈。
- 已修的两个典型循环：`EntityFluidInteraction.update`、`Entity.checkInsideBlocks`（都是 int 溢出成超大方块遍历）。
- 中文文件用 read/write/edit 工具，不要用 PowerShell 读写；提交信息中文。
- 不 push，用户控制代理。
- 第三方参考只做黑盒行为观察，代码/文档/提交里不得出现名字或链接。
