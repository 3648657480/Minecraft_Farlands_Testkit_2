## 5. 已确认的根因假设

`LevelRenderer.repositionCamera`：

```java
SectionPos cameraSectionPos = SectionPos.of(cameraPos);
this.viewArea.repositionCamera(cameraSectionPos);
```

`SectionPos.of(Vec3)` 在 2^53 走 int 截断，得到的 center 是错的/固定的，所以：

- 数据 ring 在动；
- storage center 不旋转；
- 渲染窗口留在原位；
- 边缘 section 被错误剔除。

## 7. 下一步建议架构

不要再修 `setWideAnchor` 或 key 公式的局部补丁。需要 **fixed base + local camera frame**：

```text
fixed base section（绝对，2^53 附近）
localCameraSection = cameraSection - base      // int 小值
storage center     = localCameraSection
key                = base + local node         // 世界身份
anchor             = 只影响 render origin
```

具体：

1. 在 `LevelRenderer.repositionCamera` / `ViewArea` 入口，用 fixed base 算 local camera section；
2. `SectionPos` 只承载 local 值，永远不溢出；
3. `RotatingSectionStorage` 正常旋转，只换边缘 slot；
4. key 不再依赖 camera/anchor 的变化；
5. 数据 ring 保持现有双队列/并发管线，只作为数据源。

验收：

```text

无整片重建

```
