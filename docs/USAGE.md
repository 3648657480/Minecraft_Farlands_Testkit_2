# FarLands G2 使用手册（Alpha1）

> 版本：0.1.0（发布 zip 为 `0.1.0-alpha1`）。
> 范围与验收的权威定义：[ALPHA1.md](ALPHA1.md)。安装步骤：[../INSTALL.md](../INSTALL.md)。
> 本文只描述 **Alpha1 实际可用的东西**；epoch / `/realtp` 时代的内容已随 T1 退役，
> 历史记录见 [EXPERIMENTS.md](EXPERIMENTS.md) 与 [TOMBSTONE.md](TOMBSTONE.md)。

## 1. 你能做什么

| 能力 | 状态 |
|---|---|
| 单人、真实坐标运行 | ✅ |
| 2^53 以内传送 / 渲染 / 移动 / 碰撞 / 存档 | ✅（门禁 5/5） |
| 2^53 ~ 2^63−1 | ⚠️ 尽力可用（同一管线；不额外承诺） |
| 2^63−1 以外 | ❌ 不在 Alpha1（Alpha2） |
| 距离现象 | ⚠️ 只保证**机制层可测**（见 §3） |
| 多人 / dedicated | ❌ 不支持 |
| 真实光照 | ❌ 远域是全亮护栏（阴影类现象不承诺） |

## 2. 怎么去

1. 单人世界，**开作弊**（创建世界时勾选）；
2. 进世界后传送：

```text
/tp @s 9007199254740992 150 9851     # 2^53
/tp @s 36028797018963968 150 9851    # 2^55
/tp @s 72057594037927936 150 9851    # 2^56
/tp @s 4611686018427387904 150 9851  # 2^62（2^63 区域代表点）
```

- y 建议 120~200、俯视 45°；传送后等 15~30 秒让区块编译；
- **不要**用 2^63 本身：double→long 会饱和到 long 上限，坐标不可信；
- 传送失败/画面永久为空（60 秒不收敛）才按 [BETA.md](BETA.md) 报。

## 3. 距离现象（Alpha1 口径）

在 2^53 起、z=9851、同一存档副本、安装形态下实测（2026-11-15）：

| 量级 | 密度采样层 | 说明 |
|---|---|---|
| 2^53 | 2 格一组（round-to-even） | **地表外观正常**（已知结论，不是 bug） |
| 2^55 | 8 格平台 | 与 `ulp=8` 一致 |
| 2^57 | 整块 16 列同值 | `ulp=32` > 区块 16 |

- 阈值只由量级决定、与种子无关（与 G1 `EXPERIMENTS.md` §8.1 一致）；
- **目视形态**（2^55 阶梯、2^56 平板/水面瓷砖）**尚未验证**，不承诺；
- 2^88/171.103 的"经典高墙"属 Alpha2，本版本不做；
- 现象"起点位置"随种子浮动：位置不同不算缺失，"有没有"才算。

## 4. 配置入口

三个来源，优先级从高到低：

```text
JVM 覆盖   -Dfarlands.<key>=<value>
世界文件   <世界目录>\farlands.properties
全局模板   config\farlands-g2.properties
```

- 全局模板在模组初始化时自动创建（任何世界之前）；
- 世界文件在创建世界时由 FarLands 标签页写入，或退出世界后编辑；
- **不要在运行中的世界里改配置**；
- 参数与默认值见 [CONFIG.md](CONFIG.md)。

## 5. 安全红线（R1–R6）

### R1：不要手改已有世界的 `farlands.properties`

禁止：在已有世界里改动地形/窗口类键（例如 `farlands.y.window`、`farlands.far.dataRadius`）。
原因：窗口与已生成数据绑定，改了会出现新旧段错位。
处置：系统不阻止；要实验请新建世界。

### R2：不要带着非法配置启动

禁止：写入非法值后继续启动。
原因：错误的窗口/半径会损毁世界；静默降级会把错误藏起来。
验证：已测试——`POLICY VIOLATION` + `configuration rejected; aborting JVM (fail-fast)`。
处置：**系统不会让你带着错误配置继续跑**；按日志改回合法值。

### R3：不要长期开诊断

禁止：正常游玩时开 `farlands.diag.*` / `farlands.trace.*`。
原因：逐帧/逐段日志带来磁盘与性能压力（2026-11-15 曾出现一次 2.5 分钟 1.17 GB 的日志洪水，
已在本版本修掉发布路径上的调试打印；诊断开关仍会产生产量）。
处置：只在短时诊断时开，用完关掉。

### R4：不要在现象区长时间游玩

禁止：在 2^53 以外长时间跑图。
原因：远域几何重、编译积压大；Alpha1 不承诺性能。
处置：短看/截图可以，长玩请传回正常区域。

### R5：不要在不可替代的存档上做地形/窗口实验

禁止：在唯一存档上改 `farlands.properties` 或试 `farlands.y.*`。
原因：窗口搬移与地形生成都可能留下不可逆的段状态。
处置：实验用新建世界或存档副本。

### R6：不要联机

禁止：在多人/dedicated 上使用。
原因：Y 窗口与远域推流依赖同进程客户端/服务端；dedicated 会在启动时打印不支持告警并关闭相关功能。
处置：只玩单人。

### R7–R10

项目工作准则（后果写实 / 严谨严格 / 地形生成器调试域 / 尊重外部记录），
唯一权威文本见 [../AGENTS.md](../AGENTS.md)。

## 6. 已知限制

- 2^31 缝上的结构/特征可能异常（已知 int 回绕，Alpha1 不修）；
- 远域地形可能出现 1 格沟槽/台阶，尚未定性；
- `2^63−1` 以外坐标不可信；
- 远域光照为全亮护栏；
- HUD 未并入 F3；F3+G 在远域不可用；
- `> 1.8e308` 的 double 溢出不在本版本范围（现象记录见 G1）。

## 7. 怎么验证你装对了

启动日志应出现：

```text
[FarLands-G2] 0.1.0 wide build (real coordinates)
[FarLands-G2] env cores=... maxMemoryMB=...
[FarLands-G2] farlands.* properties (n):
```

进世界后应看到 `[FARSTREAM] follow started ... radius=4` 与 `[WIDEBASE] ... established=true`。
